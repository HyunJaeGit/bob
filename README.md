# BOB 💣

위에서 떨어지는 폭탄을 피하며 오래 살아남는 웹 게임입니다.

### [▶ BOB 플레이하기](https://hyunjaegit.github.io/bob/)

## 게임 방법

1. **게임 시작** 버튼을 누릅니다.
2. `←` `→` 또는 `A` `D` 키로 플레이어를 움직입니다.
3. 폭탄을 피하며 생존 시간을 늘립니다.
4. 폭탄에 닿으면 **다시 시작**할 수 있습니다.

## 사용 기술

- HTML
- CSS
- JavaScript

## 프로젝트 구조

```text
bob/

```
